# Contributing

Corrections, questions, reproducible examples and additional genomics tutorials are welcome.

For a new tutorial:
1. State the research question and define unfamiliar terms in everyday language.
2. Explain every input and output file, including how sample identifiers are joined.
3. Include reproducible commands and what each argument means.
4. Use only synthetic or properly redistributable public datasets, with source attribution.
5. Distinguish educational examples from validated production and clinical methods.
6. Cite authoritative documentation and scientific references; include software versions.
7. Explain potential pitfalls (e.g. allele harmonization, ancestry confounding, LD, relatedness, data leakage).

Do not contribute identifiable human genomic or health data, credentials, access tokens or restricted datasets.

Until a license is selected by the repository owner, do not assume rights to copy, redistribute or commercially reuse the contents beyond those otherwise granted by law.
