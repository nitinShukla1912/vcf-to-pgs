# Roadmap

This repository is a living educational resource. Topic ideas below are not promises of completed pipelines.

## Available now
- [x] Joint-called VCF to genotype/phenotype matching, GWAS and PGS walkthrough
- [x] Synthetic, reproducible example with regression coefficients, covariates, LD and scores
- [x] Common terminology, PLINK2 command explanations and methodological limitations

## Next guides to consider
- [ ] Genomic sample QC, contamination, relatedness and ancestry assessment
- [ ] Variant normalization, annotation, pathogenicity evidence and reporting
- [ ] PCA and population-structure tutorials using public reference data
- [ ] GWAS QC, statistical power, mixed models, fine-mapping and replication
- [ ] PRS-CS / LDpred2 methods and cross-ancestry PGS validation
- [ ] Rare-variant association tests, burden tests and gene-based analyses
- [ ] Reproducible Jupyter notebooks and workflow managers
- [ ] Public/reference dataset provenance, methods reporting and data governance

## Principles
- Start each topic with a simple scientific question, then show files, examples and commands.
- Clearly label toy examples versus research-ready procedures.
- Prefer public or synthetic data and include expected outputs and explanations.
- Record tool versions, genome build, assumptions and validation limits.
